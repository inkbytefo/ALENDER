# material/ — PBR texture sets of VEH_TT92_Racing_Car

```
material/
  _source/      the AI-made albedo images as delivered (renamed to ASCII; original_names.json keeps the
                original Turkish file names) + the two usable AI normal maps
  _rejected/    afterburner_plasma_normal_BROKEN.png: not a normal map (a hue-shifted copy of the albedo)
  TT92_<Set>_1K-PNG/   one folder per material, 1024 x 1024 PNG, seamless:
      TT92_<Set>_Color.png             sRGB
      TT92_<Set>_Roughness.png         Non-Color
      TT92_<Set>_Metalness.png         Non-Color (constant 0 or 1)
      TT92_<Set>_NormalGL.png          Non-Color, OpenGL (+Y up)
      TT92_<Set>_AmbientOcclusion.png  Non-Color
      TT92_<Set>_Displacement.png      Non-Color height
      TT92_AfterburnerPlasma_Emission.png   sRGB (that set only)
  texgen_report.json   numbers of the last generation (seam ratio before/after, roughness range ...)
```
Regenerate everything from `_source/`:  `python wb.py run projects/VEH_TT92_Racing_Car/texgen.py`
(one set: `... texgen.py -- PaintRed`). Per-material numbers are in `SPECS` at the top of `texgen.py`.

## What is real and what is derived
| Map | Origin |
|-----|--------|
| Color | the AI albedo, made tileable (10 % edge cross-fade), resampled 1254 -> 1024 px |
| NormalGL | **supplied** for SteelBrushed and ExhaustWrap (re-centred, renormalised); **derived** from the height map for the other 11 |
| Displacement | derived: high-passed luminance of the albedo |
| Roughness | derived: base value + luminance-driven variation (numbers in `SPECS`) |
| Metalness | constant per material |
| AmbientOcclusion | derived: cavities of the height map |

A height map taken from albedo luminance is an approximation. It reads chips, pores, weave and brushing
correctly but does not know true depth, so normal/bump strengths are kept low. Replace any map with a
better one (same file name) and re-run stage 5.
