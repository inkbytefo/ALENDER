## Scene tree
```
Gemini                     root (Node3D)
├─ Body                    frame, engine, tank, seat, fork, swingarm, exhaust ... (static)
├─ Wheel_Front             pivot on the axle (tyre, rim, spokes, both discs)
├─ Wheel_Rear              pivot on the axle (tyre, rim, disc, sprocket)
├─ Glass                   headlight lens + reservoirs, plain transparent material MAT_GLASS
└─ Body_00-convcolonly     convex hull -> collision shape
```
Units: metres. Up = +Y. The front of the bike points to +Z after import (glTF front); wheels spin
about their local X axis.

## Import
1. Copy this folder into the project as `res://VEH_Gemini_Motorcycle/` (the `.tres` files expect that path).
2. Drop the `.glb` in a scene: Godot builds the material from the embedded textures.
3. Optional: *Import → Advanced → Materials → Use External* and pick `M_Gemini_Body_ORM.tres`
   (one texture fetch) or `M_Gemini_Body_Standard.tres` (separate maps).
4. FBX: Blender's FBX exporter writes only base colour, normal and emission links - assign one of the
   `.tres` materials after import to get roughness / metallic / AO.

## Limits
- The clear coat of the paint cannot be exported: 75 % of it is folded into the baked roughness. For the
  full gloss enable *Clearcoat* on the material in Godot.
- UVs are an automatic atlas (smart project + pack), meant for the baked textures, not for hand painting.
- One material for the whole bike: sheen (seat leather) and anisotropy (brushed steel) are not represented.
- Tyres have no tread pattern; the tank has no "HONDA X" graphic.

Conventions follow the Godot docs (*Available 3D formats*: glTF 2.0 recommended, FBX through ufbx) -
https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html
